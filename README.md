# Aprendendo PHP

Bem-vindo ao repositório **Aprendendo PHP**!

Este projeto foi criado com o objetivo de documentar minha jornada de aprendizado na linguagem PHP, reunindo exercícios, exemplos práticos, conceitos fundamentais e pequenos projetos desenvolvidos durante os estudos.

## Sobre o projeto

O repositório funciona como um espaço de aprendizado e evolução, onde compartilho meus estudos sobre PHP, desde os conceitos básicos até conteúdos mais avançados.

A ideia é praticar, experimentar e acompanhar minha evolução como desenvolvedor.

## Como executar os exemplos

1. Instale o PHP em sua máquina.

[Instalação WIndows e Linux](./docs/install.md)

2. Clone este repositório:

```bash
git clone https://github.com/horadoqa/aprendendo-php.git
```

3. Entre na pasta do projeto:

```bash
cd aprendendo-php

cd projetos
```

4. Execute o servidor embutido do PHP:

```bash
php -S localhost:8000
```

5. Acesse no navegador:

```text
http://localhost:8000
```
